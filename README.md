# MCS 444 | Windows Server 2022 Virtualization Lab 

Course: MCS 444 - Installing Windows Server 2022 on Oracle VM VirtualBox
Student: Paula Apa.

## Brief Description
This lab demonstrates virtualization using VirtualBox to install Windows Server 2022, configure a virtual network, assign a static IPv4 address, and verify connectivity using Windows command prompt.

## Configuration Values
- Virtual Network: MCS Nat -192.168.10.0/24
- IP Address: 192.168.10.254
- Subnet Mask: 255.255.255.0
- Default Gateway: 192.168.10.1
- Verification: ipconfig /all and ping to gateway with 0% loss
